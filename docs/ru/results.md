# Возобновление прогона и отчёты

[OboroLabs](../../README.ru.md) · [English](../en/results.md)

## Сохранённые прогоны

В `manifest.json` записываются конфигурация, описание окружения, хеш графа и отпечаток сервера. Для каждого PNG из `images/` в `records/` есть JSON с заданием, замерами и SHA-256 изображения.

Повторите ту же команду, чтобы пропустить проверенные задания. Если план изменился или завершённая запись повреждена, выполнение остановится. Для независимого повторного прогона укажите новую папку.

## Отчёты по времени

```bash
oborolabs report out/sample
```

`report/summary.md` показывает, сколько заданий завершено с прогревом и на свежем процессе, и содержит ссылки на CSV. В `records.csv` перечислены отдельные задания. В `timing.csv` они сгруппированы по фазе, профилю и размеру изображения. Для каждой группы отчёт показывает медиану, p95 с линейной интерполяцией и число изображений в минуту. Для одного замера p95 остаётся пустым. Число изображений в минуту равно 60, делённым на среднюю задержку. Для более устойчивого p95 используйте несколько замеров с отдельными идентификаторами случаев и seed.

## Оценки внешних инструментов

Команды Tesseract и CompBench++ и порядок запуска HPS описаны в [руководстве по оценке качества](evaluators.md).

Запустите инструмент оценки по его собственному протоколу. Сопоставьте результаты с идентификаторами завершённых заданий с прогревом из `report/records.csv`. Запишите одно конечное число для каждой комбинации задания, метрики, инструмента и его версии.

```csv
job_id,metric,value,evaluator,revision
```

```bash
oborolabs report out/sample --scores evaluator.csv --reference reference
```

`quality.csv` группирует оценки по инструменту, версии, метрике, профилю и размеру. В нём указаны средняя оценка и число оценённых заданий. `pairs.csv` сравнивает каждый профиль с выбранным эталоном по общим случаям при одинаковых размере, метрике, инструменте и его версии. Отчёт показывает охват оценок для обоих профилей, число пар, среднюю разницу оценок и медиану задержки каждого профиля на этих же парах. Разница считается как «кандидат минус эталон». Значение положительного результата зависит от метрики.

Сохраняйте исходные результаты оценивания для аудита и оценивайте неопределённость отдельно, если этого требует исследование.
